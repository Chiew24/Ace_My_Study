# Ace My Study

A learning website for students to explore subjects, lessons, course information and question banks.

## Repository structure

- `index.html` — overview page
- `login.html` — authentication page
- `subjects.html` — subject selection page
- `course.html` — course landing page
- `course-info.html` — course information
- `lessons.html` — lessons page
- `question-bank.html` — question bank
- `profile.html` — profile page
- `spm-addmath-landing.html` — SPM Additional Mathematics landing page
- `assets/css/` — stylesheets
- `assets/js/` — JavaScript modules
- `assets/images/` — shared image assets
- `.github/workflows/` — GitHub Pages deployment workflow

The existing page files remain in their current locations so the site's current links and GitHub Pages behavior are preserved.
